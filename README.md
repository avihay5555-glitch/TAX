# מחשבון מס איזון

אפליקציית דף יחיד, מהירה ומותאמת לנייד, להשוואת מס איזון פרוגרסיבי למשק בית בקיבוץ בין מנגנון ישן לבין מנגנון מעודכן.

## מה כלול

- `index.html` — אפליקציה מלאה בקובץ יחיד עם HTML, CSS ו-JavaScript ללא תלות חיצונית.
- `.github/workflows/deploy.yml` — פריסת GitHub Pages אוטומטית בכל push לענף `main`.
- `README.md` — הסבר בעברית על כללי החישוב ושלבי הפריסה.

## כללי החישוב

### 1. נקודות תקן

#### נקודות בסיס

- זוג חברים: `2.0`
- חבר יחיד: `1.3`
- חבר בודד בזוג: `1.0`

#### ילדים עד גיל 18

- ילד ראשון: `+0.7`
- ילד שני: `+0.6`
- ילד שלישי: `+0.5`
- ילד רביעי ומעלה: `+0.4` לכל ילד

#### ילדים מגיל 18 ומעלה

- `+0.1` לכל ילד

**סה״כ נקודות תקן:** סכום כל הנקודות, מעוגל לעשירית.

### 2. הכנסה לנקודה

נסמן:

- `P` = סך נקודות התקן
- `x = הכנסה נטו / P`

### 3. מנגנון ישן — תקרה 50%

- `0 ≤ x ≤ 4,000` → `0%`
- `4,000 < x ≤ 4,250` → `(x - 4,000) × 30%`
- `4,250 < x ≤ 4,500` → `75 + (x - 4,250) × 34%`
- `4,500 < x ≤ 4,750` → `160 + (x - 4,500) × 37%`
- `4,750 < x ≤ 5,000` → `252.5 + (x - 4,750) × 40%`
- `5,000 < x ≤ 5,250` → `352.5 + (x - 5,000) × 44%`
- `5,250 < x ≤ 5,500` → `462.5 + (x - 5,250) × 48%`
- `x > 5,500` → `582.5 + (x - 5,500) × 50%`

### 4. מנגנון מעודכן — תקרה 44%

- `0 ≤ x ≤ 4,000` → `0%`
- `4,000 < x ≤ 5,000` → `(x - 4,000) × 30%`
- `5,000 < x ≤ 6,000` → `300 + (x - 5,000) × 34%`
- `6,000 < x ≤ 7,000` → `640 + (x - 6,000) × 37%`
- `7,000 < x ≤ 8,000` → `1,010 + (x - 7,000) × 40%`
- `x > 8,000` → `1,410 + (x - 8,000) × 44%`

### 5. חישוב המס החודשי

- מס קבוע למשק בית:
  - זוג חברים: `2,000 ₪`
  - חבר יחיד / חבר בודד בזוג: `1,000 ₪`
- `סך מס ישן = (מס ישן לנקודה × P) + המס הקבוע המתאים`
- `סך מס חדש = (מס חדש לנקודה × P) + המס הקבוע המתאים`
- `חיסכון חודשי = max(0, מס ישן - מס חדש)`
- `חיסכון שנתי = חיסכון חודשי × 12`

> החישוב אינו כולל קרן עזרה הדדית.

## חוויית שימוש

- ממשק בעברית עם `dir="rtl"`
- עיצוב נקי בסגנון כרטיסים עם תחושת אפליקציה טבעית בנייד
- בחירת סוג משק בית באמצעות כפתורי חלוקה
- צ׳יפים מהירים לילדים עד גיל 18 עם אפשרות כוונון באמצעות כפתורי `+` / `-`
- הזנת הכנסה עם תצוגה מודגשת, שדה מספרי וסליידר מהיר
- כרטיסי KPI לחישוב המס הישן, המס החדש והחיסכון
- גרף SVG רספונסיבי עם שתי העקומות, אזור חיסכון ומחוון חי

## פריסה ל-GitHub Pages

### דרישות

- ענף ברירת מחדל בשם `main`
- הפעלת GitHub Pages במאגר

### איך זה עובד

הקובץ `.github/workflows/deploy.yml` מבצע:

1. `checkout` של המאגר
2. הגדרת Pages
3. העלאת האתר הסטטי כ-artifact
4. פריסה אוטומטית ל-GitHub Pages

### הפעלה

1. דוחפים את הקבצים לענף `main`
2. נכנסים ל-**Settings → Pages**
3. מוודאים שהמקור מוגדר ל-**GitHub Actions**
4. לאחר ריצת workflow מוצלחת האתר יתפרסם בכתובת Pages של המאגר

## פיתוח מקומי

מאחר שמדובר בקובץ HTML עצמאי ללא build, אפשר לפתוח ישירות את `index.html` בדפדפן.
