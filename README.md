# מחשבון מס איזון (ישן מול חדש)

אפליקציית Single Page בעברית (RTL) בקובץ יחיד `index.html` שמחשבת ומשווה בין מנגנון מס איזון ישן למעודכן עבור משקי בית בקיבוץ.

## מה האפליקציה כוללת
- חישוב נקודות תקן לפי סוג משק בית ומספר ילדים.
- חישוב מס חודשי כולל (ישן/חדש) כולל מס קבוע של 2,000 ₪.
- הצגת חיסכון חודשי ושנתי.
- תרשים SVG אינטראקטיבי בזמן אמת (ללא ספריות חיצוניות).
- ממשק מובייל-פירסט, רספונסיבי, ידידותי למגע.

## הרצה מקומית
1. הורידו/שכפלו את המאגר.
2. פתחו את הקובץ `index.html` בדפדפן.

> אין צורך בהתקנות או בשרת צד-שרת.

## פריסה ל-GitHub Pages

### פקודות Git צעד-אחר-צעד
> החליפו את `<YOUR_GITHUB_USERNAME>` בשם המשתמש שלכם.

```bash
# 1) יצירת מאגר מקומי (אם עדיין לא אותחל)
git init

# 2) הוספת קבצים
git add index.html README.md

# 3) יצירת קומיט
git commit -m "Add balancing tax calculator SPA"

# 4) הגדרת branch ראשי
git branch -M main

# 5) חיבור ל-GitHub repo
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/TAX.git

# 6) דחיפה ראשונה
git push -u origin main
```

### הפעלת GitHub Pages
1. היכנסו ל-Repository ב-GitHub.
2. פתחו **Settings**.
3. עברו ל-**Pages**.
4. תחת **Build and deployment** בחרו:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` ו-`/ (root)`
5. שמרו והמתינו לפרסום.
6. הכתובת תופיע במסך Pages (לרוב בפורמט `https://<username>.github.io/TAX/`).
